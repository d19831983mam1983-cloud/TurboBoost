# TurboBoost 2.0

Геймерский оптимизатор Android с Root/Shizuku: разблокировка FPS, даунскейл рендера,
твики сенсы и термалки, профили игр, авто-сессия, оверлей-монитор, тайл быстрых настроек.

## Что нового в 2.0
- **Игровой оверлей** — водяной знак «⚡ TurboBoost» появляется поверх игры; тап раскрывает
  панель: **прицел** (5 стилей, 6 цветов, размер), **снежинки** (плотность/скорость/размер),
  пинг, температура, кнопка «скрыть знак на 15 сек». Всё настраивается прямо в игре.
- **Базовая тема — чёрно-оранжевый** (стиль FACEIT из CS).
- **Авто-сессия** — профиль игры применяется сам при её запуске и откатывается при выходе
  (Настройки → Автоматизация; нужен доступ к статистике использования).
- **Оверлей-монитор** — температура/батарея/турбо поверх игр (нужно разрешение на оверлей).
- **Тайл в шторке** (быстрые настройки) — включение/выключение турбо одним тапом.
- **Экспорт/импорт** профилей и списка игр в JSON.
- **Журнал операций** — Настройки → Журнал.
- **Полный откат (revertAll)** — единая точка выхода: тумблер, батарея ≤10%, перегрев >85°C,
  смахивание приложения, тайл шторки, авто-сессия. Больше не остаётся «забытых» твиков.
- Фикс: статус не затирается предупреждением о перегреве; авто-реконнект Shizuku;
  счётчик блокировки админки не крутится на несуществующих ID; флаг изменённого разрешения.

## Сборка
./gradlew assembleRelease (нужен release.jks и env: KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD)
