# TurboBoost 2.1

Геймерский оптимизатор Android с Root/Shizuku: разблокировка FPS, кастомное разрешение экрана,
твики сенсы и термалки, профили игр, оверлей-монитор, тайл быстрых настроек.

## Что нового в 2.1
- **Разрешение экрана** — два поля (высота × ширина) + «Применить и запустить Standoff 2» + «Сбросить».
  По нажатию «Применить»: сохраняется текущее `wm size`/`wm density`, применяется пользовательское,
  запускается Standoff 2, через 25 секунд разрешение возвращается к исходному. Если приложение
  убили во время окна — откат доделается при следующем открытии TurboBoost.
- **Игровой оверлей** — водяной знак «⚡ TurboBoost» поверх игры; тап раскрывает панель:
  прицел (12 стилей, 8 цветов, размер, прозрачность, зазор, обводка, смещение X/Y, D-pad,
  центральная точка, зеркало, толстые линии, пиксельный стиль, радуга),
  снежинки (4 режима: снег/дождь/искры/листья, плотность/скорость/размер, чистая зона в центре),
  визуальные эффекты (сетка, круг FOV, виньетка, scanlines, ночной фильтр, туман, хроматика,
  линия отдачи, safe-zone, вспышка краёв, рамка радара, low-HP виньетка, letterbox 21:9,
  затемнение UI, тёплый/холодный тон, рамка миникарты),
  HUD (пинг, температура, батарея, RAM, таймер сессии, секундомер, часы, дата, тип сети,
  загрузка CPU), водяной знак (5 стилей, 5 позиций, прозрачность, пульс, неон, имя игры,
  крошечный режим, вертикальный текст, тень, обводка, бейдж, таймер и температура на знаке),
  кнопка «скрыть знак на 15/30 сек». Всё настраивается прямо в игре.
- **Базовая тема — чёрно-оранжевый** (стиль FACEIT из CS).
- **Оверлей-монитор** — температура/батарея/турбо поверх игр (нужно разрешение на оверлей).
- **Тайл в шторке** (быстрые настройки) — включение/выключение турбо одним тапом,
  с синхронизацией оверлеев и проверками root/вендора.
- **Экспорт/импорт** профилей, списка игр и настроек (Hz, режим, сенса, GPU Boost, лимит фона) в JSON.
- **Журнал операций** — Настройки → Журнал.
- **Восстановление после перезагрузки** — если турбо/авто-сессия/оверлей были активны,
  `BootReceiver` перезапускает `KeepAliveService` после загрузки телефона.
- **Полный откат (`revertAll`)** — единая точка выхода: тумблер, батарея ≤10%, перегрев >85°C,
  тайл шторки, авто-сессия (после закрытия игры). Смахивание приложения **не откатывает** —
  сервис переднего плана продолжает работать, чтобы оптимизация не выключалась у тех, кто
  закрывает TurboBoost перед игрой.
- **Фиксы:** статус не затирается предупреждением о перегреве; авто-реконнект Shizuku;
  счётчик блокировки админки не крутится на несуществующих ID; флаг изменённого разрешения;
  `SystemReader` больше не дедлочит пул при зависании `su`/Shizuku; бэкап восстанавливает
  настройки, а не только профили; `AccountStore` не удаляет аккаунты при апгрейде.

## Что убрано (было плацебо)
- **Вкладка «Игра»** (20 переключателей `g_*`) — вендор-специфично или невозможно без root.
- **Вкладка «Ещё»** (~50 переключателей `m_*`) — все плацебо.
- **Плацебо-HUD** — графики пинга/FPS, загрузка CPU/GPU, K/D, урон, точность, патроны,
  броня, killfeed, квесты, пати — нет источника данных.
- **Плацебо-эффекты** — bloom, motion blur, sharpen, ч/б, сепия, нуар, ретро, неоновые края.
- **Плацебо-прицел** — динамический размер, вспышка попадания, разброс, скрытие при ADS.
- **`switchRenderer`** — `am crash systemui` мог уронить в bootloop, плюс требует root.
- **`applySurfaceFlingerBoost`** — свойство удалено в Android 13+.
- **`tryKeepAlive`** — op `KEEP_ALIVE` не существует в AOSP.
- **`restrictBackground`** — ключ `background_process_limit` игнорируется на Android 10+.

## Ограничения
- **Авто-сессия** работает только когда турбо уже включён вручную, и завершается после первого
  отката (закрытия игры). Это архитектурное ограничение: без активного `KeepAliveService`
  нет фонового процесса, который мог бы следить за играми. Не баг, а дизайн.
- **Кастомное разрешение** меняет `wm size` всей системы, а не только игры. Пока идёт
  25-секундное окно, лаунчер/шторка тоже в новом разрешении.
- **Root-only фичи** (GPU Boost, потоки CPU, MGLRU, input dispatcher) — только при root.
  На Shizuku без root показывают «Требуется root».
- **Вендор-фичи** (`cmd game set --fps`, `--downscale`, `GPUTUNER_SWITCH`) — только Xiaomi/Realme.
  На остальных показывают «Не поддерживается на этом устройстве».
- **`touch_sampling_rate`** и `touch_prediction_enabled` — только Xiaomi/Realme. На остальных
  `applySense` пишет только `pointer_speed`/`animation_scale`/`long_press_timeout`, которые
  работают везде.
